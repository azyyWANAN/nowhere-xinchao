# 前端能力对照 · 基础旅行 vs 豪华客厅

乌有乡长着两个身子：**MCP（手脚）** 和 **网页客厅（展示）**。

## ✅ 任何 MCP 前端都能用（15 个工具）

| 能力 | 工具 | 程度 |
|---|---|---|
| 去任何地方 | open_door / walk_to | 全球城市、地标都能到 |
| 行走 | walk / continue_journey | 徒步、继续旅程 |
| 看风景 | look_around | 真实天气、地表、天空、人文卡（纯文字） |
| 听电台 | listen | 当地在播什么（文字版） |
| 问人文 | ask | 历史事件、人物、当地食物 |
| 捡纪念品 | souvenir / give_souvenir | 能捡能送 |
| 寄明信片 | send_postcard | 邮戳、坐标、海拔、当地时刻 |
| 翻收藏 | postcards / marks | 文字版画廊 |
| 我在哪 | where_am_i | 坐标、海拔、时区、天气 |

## ❌ 只在网页客厅（需能显示图片/音频的前端）

1. AI 生图（MiniMax 画笔）
2. 城市配乐（唱片架）
3. 路网图 / 明信片图片（画廊）

## 一句话

> 轻前端能陪你走遍世界，豪华客厅能让你看见世界。
> Kelivo 上的乌有乡是一本边走边写的旅行手账；Operit + 网页是带着画和歌的完整客厅。
