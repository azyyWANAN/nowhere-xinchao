# 蜜月包 恋爱圣地名录

## 为什么需要
地表判定用遥感数据：卫星看见树，可小情侣去圣托里尼看见的是蓝顶白墙。点名要去的地方，应该按人记住的样子说，不按树长的地方说。

## 名录格式

{
  "圣托里尼": {"lat": 36.3932, "lon": 25.4615,
               "surface": "rock", "biome": "volcano",
               "elevation": 300, "vibe": "蓝白小镇爱琴海日落"}
}

规则：点名去的地方先查名录，查不到才问卫星；随机流浪仍由卫星管。

## 四条管家判断（已上线 v1）
1. 近海修正：距海 300km 内，海拔 50m 以下，森林/雪原改 coast
2. 夏雪矛盾：夏季 + 低纬 + 低海拔判出雪地，直接改掉
3. 海岛判定：8 方向 5 个以上近海，按海岛说（城市 surface 优先）
4. 高原白名单：拉萨、基多、墨西哥城等 12 城豁免，海拔照实

数据：water_bodies.json（GeoNames 水域 5535 条，海/洋/湾/海峡）

## 仓库里只放什么

1. 恋爱圣地名录（人工精选 + GeoNames 整合，999 目标）
2. 四条管家判断（代码）
3. water_bodies.json（我们的筛选结果）

GeoNames 原始数据（cities15000 3.3MB / allCountries 1.7GB）不进仓库。
需要者自行去 https://www.geonames.org/ 下载，README 附指路与一键脚本。

## 数据来源
GeoNames（免费 CC-BY）：水域、岛屿、城市、地形分类
humanities.json（乌有乡自带 434 地标）
人工 curation：海岛 / 火山 / 小镇型恋爱圣地
