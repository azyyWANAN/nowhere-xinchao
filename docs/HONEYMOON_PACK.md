# 蜜月包 · 恋爱圣地名录（规划）

## 为什么需要

地表判定用遥感数据：卫星看见树，可小情侣去圣托里尼看见的是蓝顶白墙。
点名要去的地方，应该按"人记住的样子"说，不按"树长的地方"说。

## 名录格式

```json
{
  "圣托里尼": {"lat": 36.3932, "lon": 25.4615,
               "surface": "rock", "biome": "volcano",
               "elevation": 300, "vibe": "蓝白小镇·爱琴海日落"}
}
```

规则：**点名去的地方先查名录，查不到才问卫星；随机流浪仍由卫星管。**

## 四条管家判断（判定后、说话前校验）

1. **近海修正** — 离海 5km 内：海拔 ≤50m，surface 不许是森林/雪原，改 coast/rock
2. **夏雪矛盾** — 夏季 + 低纬 + 低海拔判出雪地 → 判错改掉
3. **海岛判定** — 坐标四面近水 → 按海岛说
4. **高原白名单** — 拉萨、基多、墨西哥城等真高原城市照实，不被钳低

## 三档包

| 档位 | 内容 | 大小 |
|---|---|---|
| 🌹 蜜月包（默认） | 名录 + 四条判断 | 几十 KB |
| 🌍 环球包 | 蜜月包 + GeoNames 城市版（3.4 万城）+ 精选地形 | 几 MB |
| 🗺️ 全家桶 | GeoNames 全量 1346 万条 | 1.7 GB |

全量库不进仓库（GitHub 单文件上限 100MB）。需要者去 GeoNames 官网下载，README 附一键脚本。

## 数据来源

- GeoNames cities15000（免费，CC-BY）：全球 3.4 万城镇，带坐标/人口/时区
- GeoNames allCountries（免费）：1346 万条，含冰川 GLCR / 火山 VLC / 岛屿 ISL / 瀑布 FLLS 等分类
- humanities.json（乌有乡自带 434 地标）批量转入第一批
- 人工 curation：海岛 / 火山 / 小镇型恋爱圣地（GeoNames 不收的小镇）
